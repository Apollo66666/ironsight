# 雷达数据字段表

## `radar_ball_raw.csv`

| 顺序 | 字段 | 类型/单位 | 含义 |
|---:|---|---|---|
| 1 | `shot_id` | 整数 | 所属 Session 内的击球编号。 |
| 2 | `guid` | 字符串 | 一次击球在消息流中的唯一关联标识。 |
| 3 | `page_sequence` | 整数 | 球 PRC 分页序号/起始位置。 |
| 4 | `index` | 整数/tick | 相对球跟踪起点的时间索引。 |
| 5 | `buf_idx` | 整数 | Mevo 内部雷达缓冲区索引。 |
| 6 | `flags` | 位标志 | 球 PRC 点的原始状态位。 |
| 7 | `time_tick` | 整数/tick | Mevo 设备时间计数器；会发生回绕。 |
| 8 | `time_seconds` | 秒 | `time_tick × 26.7 µs` 的换算结果；不是击球后的相对时间。 |
| 9 | `n` | 秒 | 从球跟踪起点开始的相对时间。 |
| 10 | `az_deg` | 度 | 雷达到球的综合视线方位角。 |
| 11 | `el_deg` | 度 | 雷达到球的综合视线仰角。 |
| 12 | `radial_velocity_mps` | m/s | 球沿雷达视线方向的径向速度，不是三维总球速。 |
| 13 | `dist_m` | m | 球到雷达的视线距离。 |
| 14 | `sync_idx` | 整数 | 内部同步索引。 |
| 15 | `sync_buf` | 整数 | 内部同步缓冲标识。 |
| 16 | `snr` | 原始整数 | 雷达目标回波相对于噪声的信号质量指标。 |
| 17 | `peak` | 原始整数 | 雷达目标谱峰的内部位置或索引参数。 |
| 18 | `az1_deg` | 度 | 第一组天线方位角估计。 |
| 19 | `az2_deg` | 度 | 第二组天线方位角估计。 |
| 20 | `az3_deg` | 度 | 第三组天线方位角估计。 |
| 21 | `el1_deg` | 度 | 第一组天线仰角估计。 |
| 22 | `el2_deg` | 度 | 第二组天线仰角估计。 |
| 23 | `pk0` | 缩放后原始量 | 第一雷达峰值通道。 |
| 24 | `pk1` | 缩放后原始量 | 第二峰值通道。 |
| 25 | `pk2` | 缩放后原始量 | 第三峰值通道。 |
| 26 | `pk3` | 缩放后原始量 | 第四峰值通道。 |
| 27 | `pk4` | 缩放后原始量 | 第五雷达峰值通道。 |
| 28 | `pk5` | 缩放后原始量 | 第六雷达峰值通道。 |

## `radar_club_raw.csv`

| 顺序 | 字段 | 类型/单位 | 含义 |
|---:|---|---|---|
| 1 | `shot_id` | 整数 | 所属 Session 内的击球编号。 |
| 2 | `guid` | 字符串 | 一次击球在消息流中的唯一关联标识。 |
| 3 | `index` | 整数 | 杆头 PRC 点索引。 |
| 4 | `buf_ofs` | 整数/tick | 相对撞击触发点的有符号缓冲区偏移。 |
| 5 | `phase` | 枚举字符串 | 根据 `buf_ofs` 标记为 `pre_impact`、`impact` 或 `post_impact`。 |
| 6 | `peak` | 原始整数 | 杆头目标峰值相关内部字段。 |
| 7 | `snr` | 原始整数 | 杆头回波相对于噪声的信号质量指标。 |
| 8 | `buf_idx` | 整数 | Mevo 内部杆头雷达缓冲区索引。 |
| 9 | `time_tick` | 整数/tick | 杆头点的设备时间计数器。 |
| 10 | `time_seconds` | 秒 | `time_tick × 26.7 µs`。 |
| 11 | `n` | 相对时间参数 | 杆头 PRC 记录中的相对时间参数。 |
| 12 | `az_deg` | 度 | 杆头视线方位角。 |
| 13 | `el_deg` | 度 | 杆头视线仰角。 |
| 14 | `velocity_mps` | m/s | 第一组杆头速度。 |
| 15 | `velocity2_mps` | m/s | 第二组杆头速度。 |
| 16 | `dist_m` | m | 杆头距离字段。 |
| 17 | `f30` | 缩放值 | 偏移 30 的未命名协议字段，除以 1000。 |
| 18 | `f33` | 缩放值 | 偏移 33 的未命名协议字段，除以 1000。 |
| 19 | `version` | 整数 | 杆头 PRC 子记录版本字段。 |
| 20 | `f39` | 原始整数 | 偏移 39 的未命名协议字段。 |
| 21 | `f42` | 原始整数 | 偏移 42 的未命名协议字段。 |
| 22 | `f45` | 缩放值 | 偏移 45 的未命名协议字段，除以 1000。 |
| 23 | `az1_deg` | 度 | 第一组天线方位角估计。 |
| 24 | `az2_deg` | 度 | 第二组天线方位角估计。 |
| 25 | `az3_deg` | 度 | 第三组天线方位角估计。 |
| 26 | `el1_deg` | 度 | 第一组天线仰角估计。 |
| 27 | `el2_deg` | 度 | 第二组天线仰角估计。 |
| 28 | `pk0` | 缩放后原始量 | 第一峰值通道。 |
| 29 | `pk1` | 缩放后原始量 | 第二峰值通道。 |
| 30 | `pk2` | 缩放后原始量 | 第三峰值通道。 |
| 31 | `pk3` | 缩放后原始量 | 第四峰值通道。 |
| 32 | `pk4` | 缩放后原始量 | 第五峰值通道。 |
| 33 | `pk5` | 缩放后原始量 | 第六峰值通道。 |
